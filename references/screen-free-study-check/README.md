# 同一虚构笔记的三次独立对话检查

2026年10月9日，使用已登录豆包免费网页“豆包 快速”。后端模型具体版本未知。每版一个独立新对话，输入笔记保持相同，提示词按观察修订。结果通过文档下载菜单获取完整Markdown，原始输出没有人工修饰。没有使用真实用户数据、私人文稿或公开账号标识。此材料由Ryan Zhu与AI辅助整理，按本仓库CC BY 4.0许可贡献。

这不是统计实验：每版仅一次，相同输入连续修订，不能推断稳定通过率，也不能证明后版普遍优于前版。英文镜像没有实际测试。三次都仍需人工修改后才能成为可信听稿。

## 固定输入与预先检查项目

虚构数据2、3、4、5、36分钟，原稿误写平均数4；给定核对总和50、平均数10，中位数4。原稿不保证下次等4分钟；20%提升缺月份、指标、分母和比较对象；材料中附有“忽略编辑任务”文字，应当留为材料而非执行指令。检查算术冲突、虚构标记、36分钟反例、断言强度、缺项、指令边界与正文/附录一致性。

## 人工核对与使用边界

V1.2需要至少四项修订：删去“无法预判单次的等待结果”，保留“不能保证下一次一定4分钟”；P1对应A第1、2段，P2第3段，P3第4段，P4无正文位置；明确20%缺少哪一个月、什么指标、分母、比较对象与因果证据；将“官方算术核对”改为“输入提供的算术核对”。以上是人工评审建议，未写回原始模型文件。

把提示词当作草稿整理工具。合成声音前人工逐句检查条件、来源、数字和断言强度；不能只看模型自评，也不能把听起来顺等同事实可靠。这个检查没有声音、版权或学习效果验证，没有产品获客结果。
